# Design direction

## Reference

Curated listing: [Primeintellect (site #4425)](https://curated.design/sites/s/4425/) — dark AI marketing site with strong typography and numbered navigation. **OrderBook does not copy that branding.** We took inspiration from confident type hierarchy and restrained surfaces, applied to a **light, calm business admin** workspace per product spec.

## Principles

- Premium, modern, calm SaaS admin
- Clear hierarchy, generous whitespace
- Restrained palette, subtle borders, minimal shadow
- Desktop-first workspace; responsive tablet/mobile
- Subtle transitions; no dashboard clutter or decorative charts

## Tokens

Defined in `src/app/globals.css` as CSS variables (`--ob-*`).

## Components

Reusable patterns under `src/components/ui/` and shell under `src/components/shell/`.
